# 检索与核对 API 文档

核对请求字段、必填值、scope、响应结构和 API 语义时使用。本地主题资料只提供流程和易错点，示例不能替代当前 API 契约。命令和参数以本机 CLI 的 `--help` 为准，并记录帮助提供的 Docs 链接及 HTTP 方法、路径。

## 生产文档检索顺序

1. **优先检索生产索引：** <https://developer.pingcode.com/restapi/llms.txt>。先按操作的 Docs 页面标识或 `operationId` 匹配，否则按 HTTP 方法、路径和资源匹配。大索引先下载到任务临时文件再本地检索，向上下文只返回匹配条目的名称、URL 和相关说明；有歧义时补充候选，不全文打印索引。多个操作共享路径时，还要核对查询参数或动作的区别。打开索引指向的文档确认细节，索引条目本身不是请求结构定义。
2. **回退到操作的官方 Docs 页面。** 索引不存在、无法访问、内容无效、没有匹配项，或其链接页面不可用、内容不完整时，使用命令帮助或主题资料中的生产文档地址。
3. **检索生产官方文档。** Docs 页面缺失或无法解答问题时，在 `developer.pingcode.com/restapi/pingcode/` 或 `/restapi/nexus/` 对应范围内，以操作标识、资源和动作为关键词检索。打开候选页面，核对方法和路径；不能仅凭搜索摘要或相似页面名判断。站点提供的生产 OpenAPI 文档可用于补充结构细节，只提取相关操作及其引用的结构，不要将完整文件一次性载入上下文。

生产索引可能尚未部署。遇到 404/410、超时、连接失败或无关 HTML 内容时，应执行回退，而不是阻塞已有文档的操作。检索失败或索引未命中不代表接口不存在。除非站点明确提供相应 Markdown 链接，否则不要自行给 Docs URL 追加 `.md`。

文档检索只使用 `https://developer.pingcode.com`，包括重定向目标和发现的链接。不得使用 alpha 或其他预览站点作为来源或回退。非生产 Docs 链接只能用于识别操作，再查对应生产文档，不能据此使用该环境。选择文档不会改变 CLI 已保存的 API 地址、登录或 `--base-url`。私有部署还需考虑其实际 API 版本，不能假定当前云端文档中的所有功能都已部署。

## 按需读取

- 每个任务获取一次索引并复用。不可用时在本任务中记住该结果，后续直接查官方页面；新任务或用户告知索引已发布时重新尝试，不永久缓存失败。仅操作 CLI 本地功能时，无需获取 API 文档。
- 相对 URL 以文档 URL 为基准解析。以 `/` 开头的路径相对于站点根地址，而不是 `/restapi/`。
- `#operationId` 片段不会让 HTTP 只返回该操作。站点提供单接口 Markdown 链接时优先使用；整页响应较大时，先保存原文或用工具定位锚点，只读取目标操作到下一个操作边界，保留授权和备注，不打印整页 HTML 或导航。继续读取该操作依赖的共享说明及结构。
- 核对请求所需的嵌套字段和引用类型。工具输出截断时说明缺口，通过分段或本地提取补齐，不能为控制长度省略必填字段、授权或被引用结构。被截断的示例不等于完整结构。区分说明页面与可调用端点，不要把概览或令牌使用指南当成接口命令。
- 在同一任务中复用已经核实的细节。下载缓存放在 skill 目录之外，以来源 URL 区分，并保留来源和获取时间；不得默默将过时缓存当成当前文档。

## 写入前处理未确认事项

将所选文档与本机命令实际支持的选项进行对照，文档不会为 CLI 增加不存在的命令。如果来源相互矛盾或字段无法确认，先完成有用的读取，再在受影响的写入前说明具体未确认事项。不要编造字段、切换文档环境，或通过试探性写入猜测请求结构。解释 API 细节时，链接实际查阅的生产文档页面。
